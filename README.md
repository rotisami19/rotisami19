## 🚧 What I'm building

**A sandbox game inspired by GTA**, solo, in Unity. Current systems:

| | System |
|---|---|
| 🚗 | Vehicles and realistic movement |
| 🤖 | Artificial intelligence |
| 🧍 | Ragdoll and character systems |
| 🚦 | Traffic simulation |
| 🎮 | First-person and third-person gameplay |
| 🪝 | Custom mechanics: grappling hook, swimming |
